## How to use this repository

1. Clone this repository into your preferred local location. Clone for yourself, not for collaboration. (On the pop-up window)
2. Open up the cloned folder in Visual Studio Code.
3. Open up Terminal within that folder in Visual Studio Code, and run `uv sync` to install necessary libraries.
4. Every week before the class, update the repository to the latest state with pressing `git pull` on GitHub Desktop, and run `uv sync` again.

c.f. The coding homework, usually in the Jupyter Notebook format, will be revealed after each class. *(You must upload this on Moodle every week. During final submission, you must zip the entire homework of yours into one place, and upload it also on Moodle. (It's a UAL policy, sorry for any inconvenience!) This will be told in the class when the time comes, so don't worry about it too much.)*
